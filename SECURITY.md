# Security Policy

## Supported Versions

Lyra provides security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of Lyra and our users' workspaces seriously.

If you discover a security vulnerability in Lyra (such as command injection in agent adapters, IPC vulnerabilities, or unauthorized file system access), please **do not report it publicly via GitHub issues**.

Instead, please report security vulnerabilities via one of the following methods:

1. **GitHub Private Vulnerability Reporting**: Submit a confidential report via the Security tab on GitHub.
2. **Email**: Send details to `security@ambient.dev` (or reach out to the project maintainers).

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof-of-concept.
- The operating system and version of macOS on which the issue was tested.
- Any relevant logs, screenshots, or configuration details.

### Response Timeline

- **Acknowledgment**: Within 48 hours of receipt.
- **Assessment & Triage**: Within 5 business days.
- **Fix & Public Disclosure**: We aim to release a patch and coordinated disclosure within 30 days of validation.
